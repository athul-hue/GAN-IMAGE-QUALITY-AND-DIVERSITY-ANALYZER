# GAN-Based Human Image Generation & Diversity Analyzer 🤖

An AI/ML project exploring Generative Adversarial Networks (GANs) for human image generation and image diversity analysis.

## 📌 Project Overview

Generative Adversarial Networks (GANs) are deep learning models that use two neural networks — a generator and a discriminator — to learn patterns from data and generate synthetic images.

This project focuses on exploring human image generation and examining the diversity of generated images.

## 🎯 Objectives

- Explore GAN concepts and their use in image generation.
- Understand the roles of the generator and discriminator.
- Explore visual diversity in generated images.
- Learn about deep learning workflows for image-based applications.

## 🛠️ Technologies

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/athul-hue/GAN-IMAGE-QUALITY-AND-DIVERSITY-ANALYZER.git
cd GAN-IMAGE-QUALITY-AND-DIVERSITY-ANALYZER
```

### 2. Install dependencies

```bash
python -m venv .venv
```

Activate the environment on Windows:

```bash
.venv\Scripts\activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

### 3. Run the application

Check `app.py` to confirm how the application is intended to run. If it is a standard Python script, try:

```bash
python app.py
```
